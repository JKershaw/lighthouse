# We can see pieces of the internet's AI activity, but not how they fit together

Could anyone count how much AI activity happens on the internet? Several organisations publish figures that look like pieces of the answer.

*26 September 2026 · Lighthouse*

Picture an AI agent updating a public software project. It consults a model through a broker, which publishes how much each model is used through it. It downloads the software it needs, and a download counter ticks up. It sends its change to GitHub, and a public archive logs it. If it reads documentation on a website that uses Cloudflare, that visit may be counted too. One job, up to four entries, and nothing says they belong together.

So the figures will not add. They measure different things. Adding them would count some work several times and work done out of sight not at all. No source says how much it overlaps the others, and we have not measured it.

We think the honest answer today is a set of partial counts, each with its limits stated. A smaller question can be answered now. Take one narrow slice, say a week of changes to one family of software packages. When one source sees a piece of work there, how often does another see it too?
