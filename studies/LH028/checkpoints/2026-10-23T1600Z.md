## Dated source revision

Cloudflare's newly inserted 23 October update says the PHP project published an [informational advisory](https://www.php.net/archive/2026.php#2026-10-23-1) for related CVE-2026-115560 in the session upload progress feature. It says this vulnerability affects fully patched releases, including PHP 8.5.12, and is expected to be fixed in the next regular PHP release. **This checkpoint has not independently read the linked PHP advisory**: these are Cloudflare's claims in the selected source, first observed by this collector at 16:06 UTC. The page metadata is a claimed edit time, not an observed release or exploit time.

Cloudflare also claims its WAF protects against *known exploit attempts* for sites using PHP's default upload progress field name. It explicitly says sites that changed `session.upload_progress.name` are **not covered by that WAF rule**, and identifies one of its previously listed PHP rules as the protection. This is a vendor statement about defensive coverage, not a measured number of protected sites, attacks blocked or successful compromises. The wording supplies no event-specific sensor, numerator, denominator or observation window for attempts. It provides no basis to attribute attacker activity to AI. OpenAI's earlier documented AI-assisted defensive discovery/coordination remains a separate claim.
