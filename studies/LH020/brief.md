## Fixed frame, records and events

This is one selected publisher chain, covering the four fixed upstream branches as one coordinated episode. Read the PHP project's advisory as retained in LH018; GitHub API records for exactly issue `docker-library/php#1693`, PR `docker-library/php#1694`, PR `docker-library/official-images#22541`; each PR's commits, reviews, issue events and check runs for its reported head SHA; and Actions run #39617280912 with its jobs. If the PHP PR check-run record names a GitHub Actions URL for the same head SHA, read at most one matching run and its jobs, selected lexicographically by run URL ID before examining outcomes. Keep records even if failed or empty. The official-images FAQ gives the pipeline's *declared* stages; do not silently infer a specific `docker-library/meta` build event from the generic process. No GitHub comments, logs, other PRs, other runs or `meta` data are in the initial frame; an unavailable endpoint remains unknown.

Use source-specific clocks: advisory's publication date at day precision; issue and PR `created_at`; PR `merged_at`; commit authorship and committer times as supplied (which need not equal source publication); checks' `started_at` and `completed_at`; Actions run `created_at`/`run_started_at`, jobs' `started_at`/`completed_at`; Hub `last_pushed` and `tag_last_pushed`; and Lighthouse's first retrieval time. A PR body or issue is public communication, not measured readership. A successful CI job is a test, not a registry push. Registry source timestamps are vendor metadata, and first observation is an upper bound for availability. Compare intervals only when two specified precise endpoints are for the same image path, and label an interval descriptive rather than causal. Do not convert PHP's date-only notice to 14:00 merely because disclosure was scheduled then.

## Missingness, ceiling and stop

Save full bounded HTTP response bytes, retrieval UTC, status, source URL, relevant rate-limit headers and SHA-256; retain errors rather than replacing endpoints. At most 24 external API calls and 8 MiB retained bytes, with 2 MiB per response, public unauthenticated API only. If the remaining GitHub API quota is below five, stop and record the incomplete run. Do not retrieve logs or bearer credentials. One read of each named record ends the snapshot; the collector refuses to overwrite it. A missing or inaccessible check, job or event is unknown, not a failed build. If none of the PR or CI endpoints can be read, finish with a source-feasibility account.
