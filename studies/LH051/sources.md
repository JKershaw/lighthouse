# LH051 sources

Every source read for this study, with the time it was read. The pre-brief reads touched no count: no GH Archive file from the study's hours, no GitHub page or API, no payload, workflow file, script, run log or Telegram channel. Bodies are kept gzipped under [data/](data/) with a read log (`read_log.json`: URL, UTC start and finish, status, bytes received, the SHA-256 of the bytes as received, the robots.txt decision, and how much was withheld). Collector for these reads: [scripts/collect_prebrief.py](scripts/collect_prebrief.py). Before each fetch, scripts/robots_gate.py was asked (provider anthropic); every URL below was allowed, and no wall was met.

**What is withheld from the kept bodies** (gate conditions 3 and 4): email addresses; every github.com account or repository path; owner/name tokens in the page text (how the posts name repositories and packages); and a short list of words, held in the collector only as truncated hashes: the organisations, accounts, repositories and third-party app the posts name, and the Telegram chat and bot identifiers. The posts name affected repositories, accounts and organisations, and StepSecurity names a third-party app whose users' tokens it says were used; none is named here, in the brief or in any Lighthouse file. The SHA-256 in each log is of the bytes received, so a later fetch can be compared. The posts' code blocks were not read.

Every figure from E1 and E4 is the vendor's, at the time the vendor states, quoted and not checked.
