# LH008 sources

Every network request the scripts made through HTTP is in data/read_log.csv with its UTC time, source, endpoint, status and bytes (1,141 rows, 07:17:14 to 07:26:19 UTC on 27 September 2026; data/read_summary.csv totals them by source). Each clone is one row, with the clone's size on disk when it finished. Blobs that git fetched on demand from the blobless clones while files were read at the snapshot and at later commits (07:24 to 07:39:58 UTC) are not logged request by request; the clones held 1.47 GB when made and 1.6 GB on disk at the end, so those fetches came to roughly 0.1 GB. No page of documentation was read. No key, token or credential was used; every read was anonymous.
