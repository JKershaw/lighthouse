Platform Data

Censys products are built upon the most up-to-date and accurate map of the publicly available internet built by Censys' world-leading internet scanning processes.

In the Censys Platform, this information is collected and organized into datasets for hosts, web properties, and certificates.

  • The host dataset provides comprehensive information on public IPv4 and IPv6 hosts.
  • The web property dataset contains information about internet assets that respond to hostname-based scans. They are identified by a hostname and a port. Hostnames can be name-based records (such as app.censys.io) or IP-based records (such as 104.18.10.85).
  • The Censys certificates dataset is the most exhaustive collection of X.509 documents in existence. It contains over 15 billion records and grows daily as new certificates are identified on the public Internet.

Use the content in this section to learn more about the datasets available in Platform and how to navigate them.
