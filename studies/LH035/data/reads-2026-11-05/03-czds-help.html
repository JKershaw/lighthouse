Need Access to CZDS?

Welcome to CZDS!

The Centralized Zone Data Service (CZDS) is an online portal where any interested party can request access to the Zone Files provided by participating generic Top-Level Domains (gTLDs).

Please check back often as new gTLDs will be added once they are delegated. If you are looking for the zone file of a TLD that is not listed in CZDS, please contact the Registry Operator directly and ask for their Zone File Agreement. For reference, ICANN.org maintains a list of Registries.

* We recommend using Chrome browser for the best downloading zone file experience.
