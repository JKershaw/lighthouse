What follows: pip could use PEP 658 metadata from 22.3 (15 October 2022), but PyPI offered none until 2023, and
then in its JSON index only under core-metadata, which pip reads from 23.2 (15 July 2023); 23.1.2 looks only for
dist-info-metadata. So from PyPI's JSON index, pips older than 23.2 fetch each candidate in full while resolving.
pip 23.1.2 asks an index for JSON first (pip/_internal/index/collector.py, lines 138 to 141: "application/vnd.pypi.simple.v1+json",
then "application/vnd.pypi.simple.v1+html; q=0.1"), so from PyPI it reads the JSON form. Not checked: the pips between 22.3 and
23.1.2, which were not read; what PyPI's HTML index emits; mirrors and proxies; whether the download log counts requests for
the metadata files.
