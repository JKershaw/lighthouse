## What each source is, and its limits, as far as this study relied on it

- **K1, ClickPy.** A copy, not the original: every count here is ClickPy's. Its catalogue (data/clickpy_schema.csv) gives each table's definition. `pypi_downloads_per_day_by_version` is filled by a materialised view counting `pypi.pypi` rows by date, project and version, and gives both sides of every share. `pypi.pypi` holds one row per download with the installer's name (not its version) and a `ci` column of 'false', 'true' or 'unknown'; the staging table holds `ci` as a nullable boolean, and the step between them is not in the catalogue (K5 says a null becomes 'false'). No row read for the CI subsample held 'unknown'. ClickPy keeps the day of each download, not its time. It re-ingests days it finds wrong (LH005), so a later read can differ. Limits served: 10,000 result rows, one billion rows read and 60 seconds a query.
- **K2, PyPI JSON.** The versions a project lists now, with each file's upload time; a version deleted before the read is absent, so its downloads, if ClickPy holds any, count only in the denominator. `yanked` is the state at the read; when a file was yanked is not given.
- **K3, the installers' source.** pip (both versions) sends `"ci": true` when any of BUILD_BUILDID, BUILD_ID, CI or PIP_IS_CI is set in its environment and `null` otherwise, never false (src/pip/_internal/network/session.py, with the list in utils/misc.py in 26.2.1). uv (both versions) copies the rule, citing pip 24.0, and sends true or null (crates/uv-client/src/linehaul.rs). Only these four versions were read. How PyPI's log processor turns the User-Agent into the BigQuery column was not read (its repository was refused to LH005).
- **K4, pypistats.** Daily totals per project from the same BigQuery table, with and without mirrors; used only as the brief's cross-check of ClickPy's daily totals.
- **Not read.** BigQuery itself (S20); linehaul's source; any installer other than pip and uv; pip and uv versions older than those in K3; pepy.tech (S23), which the brief did not call for.
