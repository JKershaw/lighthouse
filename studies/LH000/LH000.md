## Method

`take.json`, already held in this study's scratch directory, was parsed with Python's `json` module to get an exact field count and to separate null from non-null values; no field was transcribed by hand. The host was sampled twice with `date -u +%FT%TZ`, `cat /proc/loadavg`, `nproc`, `ps -eo pid,pcpu,pmem,etimes,comm --sort=-pcpu | head -12`, and a count of lines with state `01` in `/proc/net/tcp`, since `ss` and `netstat` are both absent from this container. Raw output for both samples is quoted in full in `observations.md`, alongside the observation record table. Processes named in the `ps` output were identified by reading `/proc/<pid>/cmdline` directly, not by calling any service. `grounded_at` came from `git -C /home/user/lighthouse rev-parse --short HEAD`; the working tree carried unrelated uncommitted edits to `CLAUDE.md` and `harbour/hb` at the time, which this study did not inspect or rely on. The founding documents named in this study's header were read in full or by section as cited. The Harbour server at `localhost:3123` was not called, and no key or token was read from the environment. The comparison note was read once and used only for the structural comparison marked as such above.
