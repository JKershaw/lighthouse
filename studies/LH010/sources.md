# LH010 sources

Every HTTP request and clone the scripts made is in data/read_log.csv with its UTC time, source, endpoint, status and bytes (1,335 rows, 09:53:19 to 10:04:41 UTC on 27 September 2026; data/read_summary.csv totals them by source). Each clone is one row, with its size on disk when it finished (629 MB in all). Blobs that git fetched on demand from the blobless clones, while changelogs were read (09:54 to 09:57, and the history of one file at about 10:00) and while pin and lock files were read at the snapshots and at later commits (10:03 to 10:18, when data/moves.csv was written), are not logged request by request. At most 0.8 GB was on disk at once; every clone was deleted when its reading was written. No key, token or credential was used; every read was anonymous. Neither GitHub's API nor its release pages were requested.
