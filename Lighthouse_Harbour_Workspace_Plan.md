# Lighthouse Harbour Workspace Plan

North star, budget and seed tickets

Founding edition 0.2 (draft) | 25 September 2026 | LH F06

Text to file when the Lighthouse workspace opens in Harbour. The workspace coordinates Lighthouse work and is also the first contained instance of what Lighthouse studies: an autopilot that leaves residue enabling its next run. Studies that use its records say so.

## North star

Lighthouse publishes one reproducible observation of a known workflow and an honest account of its limits.

We keep going until the results are interesting: writing worth reading, evidence that we are measuring real phenomena, and a clear relation to wider research. Task counts do not count. Publishing stays a human decision, as Harbour's charter already says.

## Budget

One to ten dollars a day of autonomous work, flexible as the instruments improve, with each change noted in a decision record. Pilot and flight companion sessions are outside the budget but inside the ledger. Harbour's cost endpoint is the unit; there is no second accounting.

## Seed tickets

Each ticket starts with its identifier so that it shows in Harbour's records.

**LH000 Observe one dispatch end to end.** Pick a dispatch in this workspace; this one will do. Capture what Harbour records about it, what the host shows while it runs, and what it leaves behind. Write it up with the LH F05 study skeleton and leave unfillable fields blank. Done when the write-up exists and says what could not be filled.

**I-0001 Export Harbour's records weekly.** A script that pulls this workspace's dispatch, feedback, usage and audit records through a read token and stores them with a collection timestamp. Run it every seven days so that nothing ages past Harbour's thirty-day retention. Done when one export has run and its instrument record says what it cannot see.

**I-0002 Sample the host.** A sampler for the machine that claims dispatches: process activity, busy core seconds and requests per destination, at a stated interval, tagged as Lighthouse traffic. Done when it has captured an idle baseline and one dispatch, with its own overhead measured.

**Q-0001 Start the question register.** Enter LH F04's follow-up questions with a reason each matters. Score nothing yet. Done when the register exists.

**L-0001 Keep a ledger.** Cost per study from the weekly export, split by whether a human or the autopilot initiated the work. Done when the first week's figures exist.

**C-0001 Check the sources monthly.** Fetch every source in LH F02 and note anything that has moved or changed. Done when the first check has run.

Two asks of Harbour when convenient: a study marker beside the ticket markers, and a labelled read token so that Lighthouse's collection traffic is recognisable in the audit log.
