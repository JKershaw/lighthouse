## What was learned and what next

One permanent record can support several reader views without turning navigation into a new scientific claim. The most useful distinctions were not topological: source versus event, citation versus support, historical access failure versus later verification, and reported reuse versus measured improvement. The graph helped expose where the old source pack was not actually available. The ordinary repository workflow already answered the fixed questions well.

Compare three next options. A broader research landscape would grow coverage before benefit is established. Another outward investigation would consume capacity the keeper asked this pilot to preserve. Repairing this interface's evaluation is the defensible choice: use an actual browser, then an unfamiliar human with the two fixed journeys and no coaching, recording wrong turns, source/caveat identification and mistaken interpretations. No new schedule or programme commitment is made here.

If that succeeds and the normal reviews approve release, trial a small claim/revision block on one existing investigation. Add an optional prior-evidence field to existing research-scout leads, not a fourth workflow. Track maintenance time, unsupported suggestions and an actual investigation choice changed by earlier evidence. For external scholarship, predeclare a small antecedent-paper set using the proposal's existing reviews and indexes as leads; inspect citation contexts and retain disagreements before drawing influence or outcome edges. A living history should grow by well-supported threads, with missing links visible, rather than by node count.
