 Description
 Palo Alto Networks is aware of two critical vulnerabilities in PHP: CVE-2026-109618 and CVE-2026-109619. 
 CVE-2026-109618 involves a remote code execution vulnerability where handling out-of-memory errors via longjmp() leaves request memory uninitialized due to improper control flow management, allowing attackers to reliably achieve RCE using out-of-memory (OOM) triggers.
 CVE-2026-109619 describes a remote code execution vulnerability where longjmp() fatal error handling leaves global memory pointing to freed memory regions. These regions can later be read or branched on during subsequent requests, enabling attackers to execute arbitrary code.

 Workarounds and Mitigations
 Customers with Frontier Virtual Patching (ATP Plus) on PAN-OS 12.2.4 and later versions received advance coverage, released via Threat ID 543004, which was released at 10:21 PM PT on Oct 20.
 Customers with a Threat Prevention subscription are provided with coverage against this vulnerability by enabling Threat ID 543004, 97622, 97623, 97624, 97625, 97643, 97647, 97649, 97652, 97653, 97656, 97657, 97658, 97659, 97662, 97663, 97664, 97670, 97671, 97672, 97673, 97674, 97676, 97677, 97678 (from Applications and Threats content version 9162, 9163, 9164 and later). For these Threat IDs to protect against attacks for this vulnerability:
 Route incoming traffic for the MGT port through a DP port , e.g., enabling management profile on a DP interface for management access.
 Replace the Certificate for Inbound Traffic Management .
 Decrypt inbound traffic to the management interface so the firewall can inspect it .
 Enable threat prevention on the inbound traffic to management services.
 The security risk posed by this issue on PAN-OS and Panorama is minimized by restricting access to the management interface to only trusted internal IP addresses according to our recommended best practice deployment guidelines . 
 Frequently Asked Questions
 Q.
Is GlobalProtect™ impacted? 
 GlobalProtect portal, gateway and Clientless VPN are not impacted.
 Q.
Is Captive Portal impacted? 
 The captive portal is not impacted. 
 Q.
Which part of the PAN-OS® product is affected?
 This issue strictly affects the management web interface, which includes the HTTPS web UI and XML API service. 
 Q.
Does it affect any standard dataplane interface, or specifically ones with a management profile attached?
 It affects the dataplane interface only if a management profile is attached to it. 
 Q.
When will PAN-OS fixes be available? 
 Patches will be made available as quickly as possible. Please monitor the security advisory for the latest information on mitigations and updates . 
 Q.
Are any of our products affected by the new vulnerability (CVE-2026-115560) announced by PHP?
 Current analysis shows no impact of CVE-2026-115560 on PAN-OS (NGFW and Panorama). This CVE is related to an uncommon configuration that is not used by PAN-OS. A review of impact to other products is underway. 
 Q.
Along with the PHP vulnerability, now there is a vulnerability in the brotli compression library used by Node.js. Will I need to do two updates?
 No, the same hotfix covers both the PHP and brotli vulnerabilities. The only exception is 11.2.10-h16 which only includes the fix for PHP vulnerabilities; 11.2.10-h17 includes fixes for both vulnerabilities. 
 Q.
Do the PAN-OS fixes address both PHP vulnerabilities (CVE-2026-109618 and CVE-2026-109619)?
 Yes. The released hotfixes address both CVE-2026-109618 and CVE-2026-109619.
