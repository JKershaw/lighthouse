## Five best leads

1. **Amazon's Cairn report (20 Nov), a vendor account of an autonomous agent run finding and using a zero-day.** https://aws.amazon.com/blogs/security/chinese-nexus-actors-cairn-ai-agents-found-a-zero-day-on-their-own/. New. Why it matters: it is a dated, attributed claim that agent operation (16 hours, 148 actions, no sleep) happens on the open internet, which bears on the charter's spread-and-sustain question and on "when a model finds the bug" (here a flaw found by agents, not by a lab, with Amazon's stated basis for "zero-day" being absence from databases). It also names a mistake a tester can read: the operator's own server was open, which is how it was seen. No ARTEX/credential content, so it adds nothing direct to LH055's credential-to-compute loop, but a Google statement (relayed) lists ARTEX beside Cairn as tools in use, worth reading at source.
2. **Patch clock for CVE-2026-133968: advisory, fix, KEV.** KEV listing 23 Nov (due 26 Nov); relayed fix MONAI Label 0.8.6 on 22 Nov. New. Why it matters: an agent-found flaw with an unusually well documented sequence (Amazon notified maintainers, advisory, fix, KEV within days of the post), usable for LH048-style clocks, and as a case of whether AI-found flaws reach the vulnerability record. Kept short: dates must be read from the primary advisory (not opened here).
3. **EPSS jump of CVE-2026-98432 is unexplained in public sources found; KEV still no.** KEV 2026.11.23, EPSS 0.8213 (23 Nov). Not new (tracked), but the second-order point is new: nginx2root CVE-2026-123007 EPSS rose from 0.064 to 0.278 and PHP CVE-2026-115560 sits at 0.731, so exploitation-probability scores are climbing across several watched flaws while none is in KEV. Next: LH036 and LH057 could note KEV remains silent.
4. **Gambit Security's report on the criminal Cairn use (retailers, Strix and Hermes harnesses).** Via Help Net Security, 23 Nov; primary not opened. New. Why it matters: a second, separate account of agent frameworks doing sustained intrusion work at low cost per target (about $25, relayed, figures differ), so a cost angle for "what AI activity costs"; and the 27 vs 19 victim counts differ across outlets, an example for a counting-discipline note.
5. **KEV additions in agent-adjacent software: LiteLLM (18 Nov) and now MONAI Label, plus an IoTDB MCP server credential-logging CVE (oss-security, 24 Nov).** Not new for LiteLLM; MONAI and the MCP server item are new.
