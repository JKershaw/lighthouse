# PHP watch: daily log

A few plain lines a day on what the fixed PHP panels saw, newest first, each linking the day's checkpoints. These are working records: what a source said and when Lighthouse read it, not reviewed findings. Anything that would change [the public account](../articles/php-emergency-first-reading.md) is flagged here and goes through review before it reaches that page. How the watch runs is in [the continuation plan](php-watch-continuation-2026-10-23.md).

## 29 October 2026

- **Flagged for review: a media report of successful exploitation, with named sources.** BleepingComputer reports, on 26 October, that the two October flaws were "successfully exploited in the wild". The report rests on honeypot data from Adel Karimi of Perplexity, with Marcus Hutchins of Expel confirming, and describes an attack on Apache mod_php running PHP 8.4.26, an unpatched release: "This is now confirmed RCE with usable memory disclosure, not just a crash followed by a suspicious process." The same article says the researcher called it one favourable configuration, not general reliability. It quotes Dataminr's TRACE team saying earlier activity showed "no known compromises", and says CISA had not then flagged exploitation (CISA listed both CVEs that day, LH031). This is a honeypot, not a compromised organisation, and Karimi's data, the primary source, has not been read. Separately, the search tool's summary relays a "35 shells on a honeypot" report of 24 October whose page refused the read (HTTP 502) ([sweep](php-media-sweep/2026-10-29T0630Z.md)).
- **How the 23 October instruction travels:** no change; no tracker holds a record for CVE-2026-115560 ([LH030](../studies/LH030/checkpoints/2026-10-29.md)).
- **CISA's catalogue:** version 2026.10.28 adds two unrelated entries; the two PHP entries are unchanged and CVE-2026-115560 is not listed ([LH031](../studies/LH031/checkpoints/2026-10-29.md)).
- **Products embedding PHP:** the Dutch NCSC's list changed in eight commits on 28 October. It still has 757 entries; for CVE-2026-109618, 144 record a fix (132 before), 218 vulnerable (219), 354 under investigation (365) and 40 not vulnerable. Still no column for CVE-2026-115560. Its README now links "PHP2shell observations in the wild (TU Delft)", a lead that has not been read ([LH032](../studies/LH032/checkpoints/2026-10-29.md)).
- **How far the fix has reached, by others' counts:** by Censys's classification, on 28 October (day 7) 53.0 per cent of version-reporting services were counted patched in 8.2, 52.4 in 8.3, 67.8 in 8.4 and 78.8 in 8.5. 24.4 million services, 54 per cent of those reporting a version, run branches PHP did not fix.
