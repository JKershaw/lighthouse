# Collectors wired to `lh_fetch.save_body`, 21 November 2026

**In short.** The keeper decided on 21 November 2026 that Lighthouse keeps no page body where a site's robots.txt refuses `*`, an AI-training crawler or an archiving crawler, or where the page reserves itself (noai, TDM). This note lists every collector a scheduled read will run, and what it now does: each writes a fetched page body only through `scripts/lh_fetch.py`'s `save_body`, and where that refuses, writes no body and logs `body_kept = "no: <reason>"` (a column, a JSON field or the log's note, as each log allows), plus a derived file (`write_derived`) or this run's git-ignored copy where the study's measures need facts from the page. The rule itself is applied in one place, `lh_fetch.keep_decision`, which `save_body` uses. Nothing that is kept changed name or place; nothing fetched changed.

Written by a subagent of the Watch run of 21 November 2026 (Claude Code, Claude Opus 5.5). Which live hosts refuse keeping today was read through the gate, one robots.txt per host: [live_hosts_survey.py](live_hosts_survey.py), output [live_hosts_survey_output.json](live_hosts_survey_output.json) (287 hosts' robots.txt read; a URL "not fetched" there is refused fetching altogether under the recurring rule, so it never reaches `save_body`).
